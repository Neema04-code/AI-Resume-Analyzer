🤖 About AI Resume Analyzer

AI Resume Analyzer is a web application developed using Python, Flask, HTML, CSS and SQLite.

It helps users analyze resumes, calculate a resume score, identify technical skills, suggest improvements and recommend suitable job roles.

Technologies Used

  • Python
  • Flask
  • SQLite
  • HTML
  • CSS
  • PDF Processing
